# Proposal: 成果库对接平台「教师成果库」

## Why

成果库页的系统侧仍为「待接入」占位；华科附幼教案知识库 10298 下已有「教师成果库」文件夹，产品需要以该分类文档为平台成果真相源展示。

## What Changes

- 前端按教案/周计划同一模式接入知识库分类（`category_id` / `category_key`）
- 成果库页增加「平台 · 教师成果库」分区：列表、查看、刷新、可选上传/删除
- 保留「教师录入」本地/BFF growth-records
- 环境变量与文档同步

## Impact

- 前端：`knowledge.ts`、archive 页、env
- 后端：无（知识库仍走平台 / 生产 BFF 转发）
- 数据：以知识库文档为准；不迁移 growth_records 入 KB
- 风险：未配置分类 ID 时平台分区提示配置；未登录时 401/403
